# 模型更新的重要性分层（2026-09-16）

“模型更新”只决定分类，不再自动意味着“重大更新”。更新数量、型号数量、标题中的“第一”、聚合站收录均不能独立构成重大更新或公众关注度的证据。

## 当前执行规则

1. **既有影响力基准**：`selection_policy.json.model_update_priority.reach_priors` 保存面向本日报的编辑基准。初版按用户明确举例区分 GPT、Gemini、Claude、千问、混元、DeepSeek 等主体与阶跃语音系列。它不是实时用户量或市场排名。未登记表示未知，不等于已证明不重要；可定期调整，也可由本次更新的证据突破先验。
2. **本次变化**：小补丁不给重大加分；仅宣布多款上线、型号版本或笼统“重大升级”也不给。明确新一代/旗舰发布、成本/上下文等量化变化或首次能力开放，并有可用性信息，才进入实质变化候选。当前是保守文本启发式，不能替代对真实变化幅度、对照条件及前代差异的编辑核验。
3. **证据强度**：一手来源或已登记官方账号与转述来源分开。已识别抓取失败或验证码页面不能获得重大更新资格。选源发生在抓取正文之前，因此正文抓取诊断仅在传入这些字段的复核中生效，不宣称已经打通自动抓取后重评分。
4. **公众关注度**：默认 `unknown`，加分为零。可接收 `model_attention_evidence` 中经审核、带 URL、时间和具体发现的独立报道、实际采用增长或搜索增长证据；同源转载只计一次，至少两条独立来源才计 2–4 分。按候选发布时间回看七天，便于历史重放。本轮未新增搜索/社交实时热度采集器，既有候选缺乏可靠证据时保持未知；品牌、热榜单站收录、厂商自称第一不冒充实测热度。
5. **重大更新加分**：实质变化 + 一手证据 + 既有广泛影响基准，或实质变化 + 一手证据 + 可核实的独立关注证据，获得 6 分。只有实质变化但未达到上述条件时最多 2 分。小众新模型并未被永久排除。

高通这类主体若报道的是芯片、端侧运行平台或部署生态变化，应按相应事件评价；不能仅因厂商知名而强行判成基础模型更新。本轮未修改硬件报道的整套评分规则。
