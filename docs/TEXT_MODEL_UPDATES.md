# 文本模型目录定时更新

服务器使用独立的用户级 `ai-daily-model-update.timer`，每周日北京时间
15:30 触发，随机延后最多 10 分钟。用户 `ths` 已启用 linger，退出 SSH 后仍运行。
这个任务不依赖 Codex 会话，也不会启动日报或发送邮件。日报原来的 08:30 定时器保持原样。

## 当前启用范围

目录刷新与自动评测、切换逻辑已接入。生产生成模型仍为 `gpt-6-sol`。
网关目录不提供价格，因此未填写计价的候选只记录为 `awaiting_verified_pricing`；
这不是目录刷新失败，也不会触发付费模型调用。

`config/model_update_policy.json` 管理评测预算和价格。计价必须来自实际使用的网关，
不能用官方标价猜测中转费用。`prices_usd_per_million_tokens` 的每个条目包含
`input`、`output`（美元/百万 token）、`source` 和带时区的 `verified_at`；
超过 30 天的计价需要重新核实。默认每轮最多预留 2 美元、18 次底层请求，
候选的输入与输出单价均不得超过当前生成模型的 1.25 倍。预留按输入字节数、
输出上限及可能的 TLS 回退保守计算；它不是已发生费用，真实账单以网关为准。

## 更新条件

1. 使用现有凭据查询 `GET /models`，保存完整 ID 列表及新增、移除差异。
   空列表、格式错误、网络失败保留上次成功目录和现有模型。
2. 只自动评估同一大版本 `gpt-<版本>-sol` 的更高小版本。
   不自动跨到 astra/luna、代码、音频、图片、preview 或新的大版本。
3. 价格已核实且满足预算后，每轮最多评测一个候选。
   三组固定的虚构日报样本覆盖日期/字数、研究事实/边界、旧闻与新进展区分。
   基线与候选都必须通过确定性检查；固定审核模型匿名比较，候选不得劣于基线。
   单次调用上限 90 秒，候选中位延迟不得超过基线的 1.5 倍。
4. 同一评测实现、样本、策略、请求参数和基线下，至少两轮达标且间隔至少 24 小时。
   满足条件后写入 `active.json`，北京时间次日零点开始允许新任务使用。
   这些样本是有限回归测试，不能保证所有未来日报的质量与成功率。
5. 每次日报启动时固定生成模型路由并由子进程继承，过程中目录刷新不会切换模型。
   审核始终解析原配置的基线模型（或显式 `AI_DAILY_AUTO_QA_MODEL`），图像生成配置不变。
6. 生成保留已经验证的旧模型作为回退。新模型遇到技术性 API 错误时写入隔离记录，
   后续解析回退旧模型；当前生成步骤沿原有 fallback 链重试。
   审核不通过仍由原来的修补/复审处理，不换审核模型来取得通过结果。
   被隔离的型号需要排障后明确解除隔离，定时任务不会反复启用。

## 文件与操作

默认状态目录：`/home/ths/ai-daily/runtime_state/model_updates/`。

- `catalog.json`：最近一次成功模型目录、增删差异、时间与网关标识。
- `last_check.json`：最近一次执行及候选状态、预算预留。
- `history/<run_id>.json`：每轮评测输入对应的固定样本编号、输出、判定与模型调用元数据。
- `active.json`：已批准的生成路由、旧模型链、次日生效时间和评测标识。
- `quarantine.json`：技术故障后被停用的型号及时间。

状态原子写入且文件权限为 0600；不保存 API key。生产读取缺失或损坏的可选路由时
回到原配置。更换网关或人工改变基线模型后，旧的路由批准不会沿用。

```sh
# 查看定时任务
systemctl --user list-timers ai-daily-model-update.timer
journalctl --user -u ai-daily-model-update.service -n 40 --no-pager

# 只刷新目录，不评测、不切换
cd /home/ths/ai-daily
.venv/bin/python ai_daily_workflow/scripts/update_text_models.py --refresh-only

# 暂停自动更新（已有日报继续运行）
systemctl --user disable --now ai-daily-model-update.timer
```

用户级 service 的总时限为 30 分钟、无自动重启；独立锁避免两个目录更新同时运行。
机器开机补跑若在 15:00 之前，只读取目录，不运行付费评测。
状态目录无法写入等维护故障会反映在该 service 状态中，不阻塞日报服务。
